## 0. 功能定位回顧（v1.1.15 F1–F12）

這組功能在 v1.1.15 定稿（業主 2026-08-23 拍板全部照做），核心是兩塊：

| 區塊 | 目的 | 決策碼 |
|---|---|---|
| **案件動態訊息框** | 統計頁選日期 + 類別 → 即時渲染當日消息 → 一鍵複製到剪貼簿，保全直接貼群組 | F1 / F2 / F3 / F5 |
| **訊息模板系統** | manager/admin 在獨立頁維護「報告模板 / 無更新模板」的文字與變數 | F6 / F7 / F8 / G7 |

兩者透過 `templateEngine.render(body, ctx)` 串起來：**後端回傳純資料 + 模板 body，前端用模板引擎渲染成純文字再複製。**

## 3. 簡化方向提案（供業主選擇，待拍板）

> ⚠️ 依 CLAUDE.md 規則 12：以下為**建議**，未經明確指示前不改規格、不觸碼。

### 方案 A —「後端直接吐成品」（瘦身幅度最大，推薦優先評估）
- daily-report **後端直接渲染最終文字**回 `message` 欄位；前端只負責「複製貼上」這一步。
- **可刪除**：`public/templateEngine.js`、`src/lib/templateEngine.ts`、`tests/templateEngine.test.ts`，以及 app.js 的渲染/預覽區塊（textarea 即時預覽可省）。
- 模板仍是 `options.body` 純文字字串；後端用極簡替換（甚至固定格式）即可。
- 效果：砍掉雙份引擎 + 前端編輯器級預覽，留下一條最短路徑：**選日期/類別 → 貼上**。

### 方案 B —「保留引擎、砍管理頁」（中等瘦身）
- 保留 templateEngine 與 daily-report，只簡化 F7 管理頁：移除變數插入面板 / IntelliSense，改 CLAUDE.md 既定做法「後台直接改資料庫」。
- 收掉重複 mock fixture（line 46~59 與 line 1694 合為一份）。

### 方案 C —「最小改動」
- 僅修 bug、抽離重複 fixture，引擎與管理頁原樣保留。

## 6. 業主新決策與衝突審查（v1.1.15 → v1.1.16 · 已定案，待 R-1~R-4 微調即施工）

> **業主最終方向**：全前端渲染；保留管理頁但合併成單 tab；只接受兩種模板（新案件、時間軸）；預設顯示目前設定；存檔就地覆寫（不用多列版本）；留本地即時預覽。
> 以下為審查結論與施工前最後確認。**未明確指示前不施工、不改規格（CLAUDE.md 規則 12 / 12.1）。**

### 6.1 🔴 硬衝突已解決：`UNIQUE(type, label)` vs 「舊停用不刪除」

```sql
-- migrations/0001_init.sql 第 30 行（0002_seed 一字不可改）
UNIQUE(type, label)
```

業主澄清：撞 UNIQUE 時就「把撞到的那條改成 active、其他改成停用」。但 `UNIQUE(type,label)` 下**同一 label 全表只有一列**，根本不會有「其他列」可切換 → **實際上就是原地覆寫 body**。

→ **結論：不改 migration、保留 `UNIQUE(type,label)`。PUT = `UPDATE ... SET body=? WHERE type/label`。**（C1 雙份引擎問題則靠「砍後端引擎」解決，見 §6.3 架構。）

### 6.2 🏁 最終訊息格式

有實際內容時：
```
修繕系統簡報：8月26日

1. ○○路　詢價中　報修描述文字
2. △△穴　已派單	留言內容

https://liff.line.me/2008484338-AvdMWQQg
```
完全無動態時（硬編兜底文案）：
```
修繕系統簡報：8月26日
今天無新案件

今天沒有案件狀態更新
```

### 6.3 五點決議對進實作 + 架構

| 業主決議 | 實作結論 |
|---|---|
| Q-1 撞到就激活撞到的那條、停用其他 | 「只有一列」＝**原地覆寫 body**；不改 migration、UNIQUE 保持 |
| Q-2 兩空固定文案 | header + 两段空白文案硬編：`今天無新案件` / `今天沒有案件狀態更新` |
| Q-3 新案状态=詢價中、訊息=描述 | 新案件列 `編號.地點.詢價中.描述`；時間軸列 `編號.地點.狀態.留言` |
| Q-4 只一個總系統連結 | 結尾一行 `https://liff.line.me/2008484338-AvdMWQQg`（僅有實際內容時放）|
| Q-5 預覽不回頭找後端 | **前端本地即時預覽** → 保留 `public/templateEngine.js`，兩頁都用它 |

**架構（關鍵）：全前端渲染。** daily-report 回傳 raw data + `new_case` / `timeline` 兩個模板 body；`public/templateEngine.js` 拼成品（管理頁預覽 + 統計頁複製）。**砍掉後端 `src/lib/templateEngine.ts`** → C1 雙份引擎問題解決。

Editable = **2 個**（new_case / timeline 正文）；header＋兩段空白文案＋系統連結＝硬編固定。
