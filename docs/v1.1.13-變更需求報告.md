## 第五輪：編輯頁欄位帶入 Bug（已修復＋補測試）

**用戶回報**：編輯案件時，案件說明不會從原本資料帶入。

### 根因
`el()` helper 對 `value` 屬性走 `node.setAttribute(k, v)`，但 **`<textarea>` 用 `setAttribute('value', ...)` 無效**（textarea 的 value 是 property，不反映 attribute）。編輯頁 `descEl = el('textarea', { value: t.description })`（app.js:1068）因此說明欄永遠空白。

### 影響範圍
- 編輯頁四欄：類別/地點/廠商用 `<select>` + `selected`（有效）；**僅說明欄受影響**（textarea 用 `value`）。
- 全站 `el()` 只此一處對 textarea 用 `value`，無其他受害者。

### 修復
- `public/app.js` `el()`：加 `else if (k === 'value') node.value = v`，`value` 一律走 property（textarea/input/select/option 都正確）。

### 測試補齊（用戶要求：不只說明，四欄都要補）
- E2E 新增「編輯頁：四欄都從原案件資料帶入（類別/地點/說明/廠商）」——進 `#/edit/2`，驗證類別=門禁、地點=大廳、說明=測試說明、廠商=測試廠商 四欄都帶入。
- 修復前此測試會 fail（說明欄空）；修復後通過。

### 驗證
- `node --check` 過、typecheck 過。
- CI 全綠：test success + e2e success，**14 E2E 全過**（含新增的編輯四欄測試）。
- 瀏覽器實測（v=1.1.13 新快取）：textarea 帶入「測試說明」✅。類別/地點/廠商帶入正常。
