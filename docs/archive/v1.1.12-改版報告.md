# 改版報告 — v1.1.12 三個功能

> 版本：v1.1.12 ｜ 日期：2026-08-21 ｜ 狀態：已施工、CI 全綠、已部署 production

本版在 v1.1.11（六份 code review 51 項補強）基礎上，實作 **3 個功能**：處理中拆為詢價中／已發包、發包金額統計、分享連結動態標題。以下為完整說明。

---

## 一、功能 1：處理中拆為詢價中／已發包（狀態語意）

### 需求
原本「待處理」與「處理中」兩段，改為：**詢價中**（待處理）→ **已發包**（處理中），且已發包時要記錄金額。

### 設計決策
- **不新增狀態值、不動 Tab 結構**：沿用既有 `open` / `in_progress` / `done` / `void`。
- `open` 顯示改名「**詢價中**」；`in_progress` 顯示維持「**處理中**」，但**語意代表「已發包」**。
- 首頁 6 個 Tab 結構不變，僅「待處理」改名「詢價中」。

### 程式碼變更
| 檔案 | 變更 |
|---|---|
| `public/app.js` | `statusBadge()`：`open` 顯示「詢價中」；首頁 tab「待處理」→「詢價中」；留言框狀態下拉加「🟡 標記已發包」 |

### 影響
- 列表、詳情頁、統計、篩選的狀態顯示同步為新語意。

## 二、功能 2：發包金額必填＋金額統計＋金額顯示

### 需求
1. 改成「已發包」時**必填金額**。
2. 統計頁**各類別金額，以發包時間為記錄基準，每月統計**。
3. 詳情頁與時間軸要**顯示金額**。

### 設計決策
- 金額存 `tickets.amount`（發包金額）＋ `tickets.amount_at`（發包時間，統計月份基準）。
- 時間軸的已發包更新也存 `ticket_updates.amount`（供時間軸顯示）。
- 「詢價中」（open）不計金額。
- 統計新增獨立端點，以 `amount_at` 月份分組。

## 三、功能 3：分享連結動態標題

### 需求
通訊軟體（LINE）分享派工連結時，卡片標題顯示**案件標題**（如「電梯－頂樓 #0006」），而非寫死的「派工單」。

### 關鍵限制
通訊軟體在**分享瞬間**抓取 `/share.html` 的 `<title>`，此時 JS 尚未載入、也未知 token 對應案件。**純前端改 `document.title` 無效**。

### 解法
把 `/share.html` 改由 **Pages Function 動態渲染**：server 端讀 token → 查 D1 → 組 `<title>` 再回傳 HTML。

### 程式碼變更
| 檔案 | 變更 |
|---|---|
| `functions/share.html.ts`（新增） | 攔截 `/share.html`；依 token 查 D1 組「{類別}－{地點} #{id}」進 `<title>`；token 無效回「派工單」預設；HTML escape 防 XSS；回傳完整安全標頭 |
| `public/_routes.json` | include 加 `/share.html`（讓 function 攔截） |
